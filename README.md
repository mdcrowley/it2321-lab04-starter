# IT-2321 Lab 4: Objects, Validation, and Error Handling

**Week 8 | Reading: Eloquent JavaScript, Chapters 6 and 8**

This lab is practice with modeling a small domain with objects or a class, validating input, handling errors, and writing a few simple tests.

## Getting started

1. Rename this repository to `it2321-lab04-lastname` (your last name, all lowercase) and set it to Private.
2. Clone it and open the folder in Visual Studio Code.
3. Open `index.html` in your browser, and open the developer console to see your output.
4. Write your code in `script.js`, replacing each `TODO` with your own work.

## What to do

- Model a small domain with an object or a class that has methods.
- Validate input so bad values are rejected, not silently accepted.
- Use try/catch to handle at least one error without crashing.
- Write at least three tests using the assert() helper.
- Aim for methods that fail cleanly on bad input.

## Files

- `index.html` — the page that loads your script. You usually do not need to change much here.
- `script.js` — where your work goes.
- `styles.css` — basic styling you may adjust.
